# OMNIFORGE v0.8 — Offline Knowledge Vault and Calm Graphite Interface

**Budget:** ₦0, no new paid services, no extra Workers AI inference on knowledge synchronization.

## What is implemented
- Browser-based local knowledge retrieval from a bounded XML starter pack. XML is only a serialization format, **not** an AI model; local answers are retrieved saved text, not generated by an LLM.
- The bundled starter pack includes 36 basic educational entries. On startup and once per hour **while the app is open**, it checks the deployed same-origin XML file for updates. No automatic hourly AI "learning"; no update is guaranteed with the app closed.
- A separate IndexedDB knowledge store (not tied to an individual chat) for reference content.
- A **Cloud AI / Local knowledge** switch. Local mode does not invoke Cloudflare Workers AI. Network outages, provider failures and quota errors attempt local fallback. The UI labels replies as local and includes the stored topic/source. Unmatched questions admit the limitation.
- Explicit **Remember** button on eligible MIKEE text replies. AI-generated answers are **not automatically** copied into knowledge, are not independently verified, and must be selected by the user.
- Import user XML packs (up to 2 MB and 2,000 records each), add individual question/answer records, and export XML backup; records remain on the same device.
- Service worker caches the application shell for subsequent offline visits. It never caches chat API requests, response payloads or user messages.
- A calm charcoal/gray/ivory theme replacing purple accents.
- Browser storage usage and estimated available quota display; explicit optional request for persistent storage.

## Testing
The build command checks syntax on offline modules/service worker and runs automated knowledge-matcher tests. Live Android browser testing is still required. Suggested tests: switch Local knowledge and ask "What is a diode?", ask a random unrelated question and check honest no-match, import XML, save a MIKEE text reply deliberately, check offline navigation after initial visit, and switch back to Cloud AI. Check website generation still works.

## Strict limitations and zero-cost safeguards
- This is **not** an independent general-purpose AI, local neural model or encyclopedic database. It cannot independently reason about unfamiliar questions.
- Background refresh while an app is closed is **not guaranteed** by the browser. The implementation checks only on launch and at most once/hour while the tab runs. A genuine background updater would require extra backend infrastructure, review, quota accounting and curated public source feeds.
- Even a large XML knowledge file cannot represent "everything". Local storage is device/browser dependent and may be evicted. The per-file import limit protects low-memory mobile browsers; multiple small XML packs may be imported.
- Knowledge may be stale or wrong. Labels and source information are exposed. User-approved saved AI responses are not verified. Never disguise retrieved text as live inference.
- No broad internet crawling, undisclosed scraping of private chats, paid model calls, cross-device synchronization or new credentials.
- Cloudflare Free's daily Workers AI allocation may stop inference and reset automatically (check official current Cloudflare documentation); the local reference library remains available after initial installation and download.
